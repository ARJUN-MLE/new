# Typely

A small, polished typing speed tester built with React, TypeScript, Vite, and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. For a production build:

```bash
npm run build
npm run preview
```

## Included

- 30-second typing tests with randomized passages
- Live WPM, accuracy, time, and character counts
- Character-level correct, incorrect, and current feedback
- Completion results with correct words and errors
- Light/dark theme saved in `localStorage`
- Optional Web Audio typing feedback, off by default
- Responsive layout with no backend or account required
